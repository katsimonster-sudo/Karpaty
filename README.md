# 🌲 «Дожити до фініша...» — Веб-сайт Карпатських мандрівок

Сучасний інтерактивний веб-портал, присвячений гірським походам Українськими Карпатами (Чорногора, Ґорґани, Свидовець, Мармароси, Боржава).

---

## ⛰️ Особливості та сторінки

1. **Головна (`index.html`)**:
   - Живий погодний інформер для карпатських масивів.
   - Інтерактивний тест підбору маршруту (Trail Matcher).
   - FAQ з гірської безпеки та контакти рятувальних постів ДСНС.
   - Вітрина топ-походів та блок донатів.

2. **Подорожі (`trips.html`)**:
   - Каталог із 15 експедицій за 2024–2026 роки.
   - Інтерактивна топографічна карта на базі Leaflet.
   - Калькулятор часу ходи за формулою Нейсміта та підрахунок калорій.
   - Динамічний профіль висот (SVG Elevation Profile).
   - Завантаження готових GPX-треків для Garmin / OsmAnd.

3. **Каталог спорядження (`gear.html`)**:
   - Інтерактивний конструктор рюкзака (Pack Builder) з Ultralight-шкалою ваги.
   - Додавання власного спорядження з локальним збереженням.
   - Пошук, сортування та гід по догляду й польовому ремонту.

4. **Спільнота & Знайомства (`community.html`)**:
   - Дошка пошуку попутників у походи з фільтрами за масивами.
   - Живий журнал гір (Trail Guestbook) для відгуків та вражень.

5. **Донат на подорожі (`donate.html`)**:
   - Підтримка експедицій через **Monobank** (картка + Банка), **ПриватБанк** (Приват24) та **PayPal**.
   - Пресети сум та прогрес-бар цілі збору.

6. **Офлайн-режим (PWA)**:
   - Підтримка роботи без інтернету на високогір'ї через `sw.js` (Service Worker).

---

## 💻 Технологічний стек
- **HTML5 Semantic**, **Vanilla CSS3 Glassmorphism** (без важких фреймворків).
- **Vanilla ES6+ JavaScript**.
- **Leaflet.js** для мап.
- **PWA Service Worker** для автономного режиму в горах.

## 🌐 Публікація на GitHub Pages
1. Створіть новий репозиторій на [GitHub](https://github.com/new).
2. Запушіть цей код у гілку `main`.
3. У репозиторії перейдіть у **Settings** → **Pages** → оберіть **Deploy from a branch** (гілка `main`, папка `/ (root)`).
4. Сайт стане доступним за посиланням `https://<ваш-юзернейм>.github.io/<назва-репозиторію>/`.
