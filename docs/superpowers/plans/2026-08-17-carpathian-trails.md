# Реалізація веб-сайту «Дожити до фініша...» — План впровадження

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Створити преміальний багатосторінковий веб-сайт про карпатські мандрівки «Дожити до фініша...», що містить 15 походів (2024–2026 рр.), каталог спорядження з вагами та статусами, інтерактивну дошку знайомств для пошуку попутників та гібридний чат-віджет.

**Architecture:** Багатосторінковий веб-додаток на чистому та швидкому сучасному стеку (HTML5, Modular CSS3 Design System з Glassmorphism, ES6+ JavaScript модулі) з централізованим керуванням даними у `js/data/`, підтримкою LocalStorage для чату й дошки оголошень, а також готовністю до запуску на будь-якому сервері чи хостингу.

**Tech Stack:** HTML5, CSS3 (Modern Variables, Flexbox, Grid, Glassmorphism, Micro-animations), Vanilla ES6+ JavaScript, Lucide Icons, Google Fonts (Outfit, Inter), LocalStorage API.

**Spec:** `docs/superpowers/specs/2026-08-17-carpathian-trails-design.md`

## Global Constraints

- Назва та логотип сайту: «Дожити до фініша...»
- Формат: Багатосторінковий (окремі `index.html`, `trips.html`, `gear.html`, `community.html`)
- Подорожі: 15 походів (по 5 за 2024, 2025, 2026 роки) із фіксацією маршруту, POI точок, перепаду висот та медіа
- Спорядження: Категорії, точна вага в грамах, опис функціоналу, статуси («У моєму рюкзаку» / «У планах придбати»)
- Спільнота: Дошка оголошень для пошуку попутників + контакти автора
- Чат: Гібридний чат-віджет із швидкими питаннями, збереженням у LocalStorage та переходом до Telegram
- Дизайн: Темна карпатська тема (глибокий графіт, хвойний смарагд, теплий бурштин сонця/вогнища)
